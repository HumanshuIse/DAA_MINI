THE RECURRENCE
T(n) = 2T(n/2) + O(n)

Each level splits the input into two halves, while merging scans all n elements. There are log n levels, so the total work is O(n log n).

Best, average, and worst case

Ordinary merge sort keeps splitting and merging even when data is already sorted. Therefore random, sorted, and reverse-sorted inputs all remain O(n log n); patterns may only change constant factors.
